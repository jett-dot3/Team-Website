The Business Challenge

Bridging Retail Operations with Systematic Data Intelligence

In fast-paced retail and service environments—such as lawn equipment parts distribution and seasonal lawn & garden merchandising—inventory levels shift rapidly. Historically, auditing stock depended on manual physical counts, sporadic spreadsheet updates, and reactive replenishment requests.

When unexpected demand surges occurred, items frequently stocked out before purchase orders could be issued, resulting in delayed customer repairs, lost retail sales space, and damaged client trust. The goal of this project was to establish an automated pipeline that connects transactional sales velocity with dynamic reorder points to provide proactive decision support.

Technical Architecture

End-to-End Analytics Workflow

How raw transaction logs are processed through a structured Python ETL pipeline and translated into actionable manager dashboards.

1. Data Ingestion

Ingests multi-source data including daily Point of Sale (POS) register outputs, supplier lead-time catalogs, and warehouse inventory CSV exports.

2. Python ETL Engine

Standardizes SKU identifiers, handles missing records, computes 30-day moving sales velocity, and calculates dynamic safety stock thresholds.

3. Decision Dashboard

Presents categorized stock health KPIs, automated high-risk restock flags, and recommended reorder batch sizes directly to purchasing decision-makers.

Code Implementation

Automated Restock Threshold Logic

Core Python snippet responsible for evaluating daily run rates and flagging vulnerable items before stockouts occur. 

# inventory_analytics.py — Dynamic Safety Stock & Reorder Point Engine
import pandas as pd
import numpy as np

def evaluate_inventory_risk(df, supplier_lead_time_days=5, service_factor=1.65):
    """
    Evaluates retail SKUs to flag high-risk stockout items based on daily sales variance.
    service_factor = 1.65 represents a 95% service level buffer against unexpected surges.
    """
    # Compute daily run-rate and safety stock buffer
    df['daily_velocity'] = df['units_sold_30d'] / 30.0
    df['safety_stock'] = (
        service_factor * df['daily_velocity_std'] * np.sqrt(supplier_lead_time_days)
    ).round(0)
    
    # Reorder point: expected demand during lead time + safety stock
    df['reorder_point'] = (
        (df['daily_velocity'] * supplier_lead_time_days) + df['safety_stock']
    ).round(0)
    
    # Classify stock health status
    conditions = [
        df['current_stock'] <= df['reorder_point'],
        df['current_stock'] <= (df['reorder_point'] * 1.25)
    ]
    labels = ['High Risk', 'Moderate Risk']
    df['risk_level'] = np.select(conditions, labels, default='Optimal')
    
    # Calculate recommended order quantity to reach target max level
    df['recommended_order'] = np.where(
        df['risk_level'] != 'Optimal',
        (df['max_capacity'] - df['current_stock']).clip(lower=0),
        0
    )
    return df[df['risk_level'] != 'Optimal'].sort_values(by='daily_velocity', ascending=False)
